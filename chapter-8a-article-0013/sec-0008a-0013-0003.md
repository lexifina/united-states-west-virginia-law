# §8A-13-3. Extension.
The time limit in §8A-13-2 of this code may be extended. The
following applies:
The time limit in §8A-13-2 of this code is extended if a request
requires prior approval of a state or federal agency. The time limit
is extended to 60 days after the required prior approval is granted.
The extension may not exceed 60 days, unless approved by the
applicant.
An applicant may request an extension in writing.
